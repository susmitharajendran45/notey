# notey
a cute but professional notepad just like the one's on our desks!


A cozy, lightweight tear-off notepad for your desktop. Built for quick thoughts without the bloat of complex note apps.

### Features

* **Tear-off sheets:** Tearing plays a crisp sound, drops a little confetti, and saves the page to an archive.
* **Archive & search:** Revisit or restore any torn note by date or text snippet.
* **Pinned mode:** Pin always-on-top so your quick scratchpad stays in view.
* **Custom papers:** Cycle between ruled, grid, dots, or blank pages across warm paper tints.
* **Quick tools:** Inline math (`25 * 4 =`), task checklists, strikeout pen, resizable tables, and image pastes.
* **Export:** One-click clean PNG snapshot or Markdown (`.md`) file.
* **Lightweight:** Tiny memory footprint powered by Tauri v2 and Rust.

### Setup

```bash
git clone https://github.com/your-username/notey.git
cd notey
npm install
npm run tauri dev

```
